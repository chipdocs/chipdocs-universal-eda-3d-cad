## 1-Command Universal CLI (Zero Dependencies — Python 3 Standard Library)
```bash
# Download any of 7,900+ components in any combination of formats:
python3 chipdocs_cad_cli.py STM32F103C8T6 --format orcad_edif,allegro_scr,pads_asc,diptrace_asc,step_3d
python3 chipdocs_cad_cli.py ESP32-S3-WROOM-1 --format fusion_lbr,altium_lia,kicad_zip,freecad_macro,openscad_scad
python3 chipdocs_cad_cli.py NRF52840-QIAA-R --format cadstar_cpa,designspark_eil,ipc2581_xml,autocad_dxf
```
